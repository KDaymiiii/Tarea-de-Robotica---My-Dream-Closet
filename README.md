# 👗 Dream Closet — Outfits, Colores y Estilos

Página web de moda con ideas de outfits, combinaciones de colores y guías de estilos.

## ✨ Características

- **Lookbook de outfits** — 9 combinaciones listas para copiar, filtrables por ocasión (casual, trabajo, noche, fin de semana)
- **Paletas de colores** — 6 combinaciones con códigos HEX copiables con un clic
- **Reglas de teoría del color** — 60-30-10, temperatura del color, neutros como ancla y más
- **Guía de estilos** — Minimalista, Streetwear, Romántico, Clásico y Bohemio en pestañas interactivas
- **Tips de guardarropa** — Consejos prácticos para sacar más partido a tu clóset
- **Interactivo** — Filtros, pestañas y copiado de colores HEX al hacer clic

## 🛠️ Tecnologías

- HTML5
- CSS3 (variables, grid, responsive design)
- JavaScript vanilla (sin dependencias)
- Google Fonts: Playfair Display + Inter

## 🚀 Cómo verla

Abre `index.html` directamente en tu navegador, o súbelo a GitHub Pages:

1. Crea un repositorio en GitHub
2. Sube los archivos (ver comandos abajo)
3. En **Settings → Pages** selecciona la rama `main` y guarda
4. Tu página estará en `https://TU-USUARIO.github.io/NOMBRE-REPO/`

## 📤 Subir a GitHub

```bash
git init
git add .
git commit -m "Primera versión de Dream Closet"
git remote add origin https://github.com/TU-USUARIO/NOMBRE-REPO.git
git branch -M main
git push -u origin main
```
